Lab 1.1: Potentiometer

## 📁 โครงสร้างไฟล์ในโฟลเดอร์ (File Directory)

| `Simulink_Lab1.1.slx` | Simulink Model | แบบจำลองการรับสัญญาณอนาล็อกจาก STM32/ADC และวงจร Schmitt Trigger |

| `Code_Potentiometer_Linear.m` | MATLAB Script | โค้ดอ่านและประมวลผลข้อมูล Linear Potentiometer (Type A & Type B) |

| `Code_Potentiometer_Rotary.m` | MATLAB Script | โค้ดอ่านและประมวลผลข้อมูล Rotary Potentiometer (Type A, B, C) |

| `Garph_Potentiometer_Linear.m` | MATLAB Script | สคริปต์สำหรับพล็อกราฟเปรียบเทียบคุณลักษณะ Linear Potentiometer |

| `Garph_Potentiometer_Rotary.m` | MATLAB Script | สคริปต์สำหรับพล็อกราฟเปรียบเทียบคุณลักษณะ Rotary Potentiometer |

| `Garph_Potentiometer_Schmitt_Trigger.m` | MATLAB Script | สคริปต์พล็อกราฟตอบสนองของวงจร Schmitt Trigger |
